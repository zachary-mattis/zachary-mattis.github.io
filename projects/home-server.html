Oathgate home server

A spare desktop I was given, now running Ubuntu Server and a set of self-hosted services in containers. I named it Oathgate, after The Stormlight Archive, which seemed fitting for a server that hosts my book library. It is still a work in progress.

Home labUbuntu ServerContainersTailscaleIn progress

At a glance

Hardware
A gifted spare desktop computer
Software
Ubuntu Server, services in containers, Tailscale for remote access
Status
In progress: hardware upgrade and security hardening are next

What runs on it

  • BookOrbit: a book and audiobook library with synced narration, which replaced Kindle and Audible for me.
  • Storyteller: an ebook and audiobook syncer I used before BookOrbit added that feature itself (its read-along alignment runs on my Mac).
  • Vaultwarden: a self-hosted password manager.
  • AdGuard Home: network-wide ad and tracker blocking.
  • Uptime Kuma: monitoring and alerts for the other services.
  • FreshRSS: an RSS reader for tech and security news.
  • Mealie for recipes and meal planning, Actual Budget for budgeting, and IT-Tools for encoders, hashes and converters.

A problem I ran into

Away from my home network, the BookOrbit companion apps on my phone and iPad could not stream from the library. Tailscale was my answer. It lets me add new devices quickly, including family members' devices, so they can share the library.

What is still rough

Tailscale gives me occasional connection issues, and I am looking at other options.

What is next

I plan to upgrade the hardware to host a media server for friends and family, and to strengthen the server's security.
