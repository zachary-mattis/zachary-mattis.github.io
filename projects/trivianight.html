TriviaNight

A Swift app that writes trivia rounds from a theme and runs the whole game, used at Ponfeigh Distillery in Somerset, PA.

SoftwareSwiftmacOSClaude API

At a glance

Problem
Writing questions and running a trivia night by hand takes a lot of work.
Built with
Swift on macOS, with Claude generating the questions
Result
I give each round a theme, review the questions, and run the game from one app. In use at Ponfeigh Distillery.

Why I built it

I run trivia nights, and I wanted to stop building every game by hand. The goal was simple: give the app a theme for each round, get a full set of questions back, and run the game from the same place.

Building a game

For each round I enter a theme and the app uses Claude to research and write the questions. It can make multiple choice, true/false and write-in answers, with image and music questions coming soon. A step-by-step wizard walks through setting up the game. If a question or a whole round is not right, I regenerate it, or I edit it by hand. I can also pick a color theme.

Running a game

When the game starts, the app projects a slideshow on one screen and shows a game master screen on the other. From the game master screen I move between questions, control Spotify music between rounds, and keep score. The scorecard updates the slides live with the rankings and shows the final winners at the end.

What came out of it

Running it at venues where the projector had no convenient outlet led me to build a cordless projector power supply.
