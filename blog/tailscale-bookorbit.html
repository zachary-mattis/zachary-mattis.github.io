Getting my book server to work away from home

Zachary Mattis
November 18, 2026

My home server runs BookOrbit, a shelf for digital books and audiobooks with narration syncing, which replaced Kindle and Audible for me. It worked well until I left the house.

The problem

When I was not connected to my home network, the companion app on my phone and iPad could not stream anything from the server. A library that only works on the couch is not much of a library.

What I did

I set up Tailscale. It let me add new devices to the library quickly and easily, and my phone and iPad can now reach the server from anywhere.

What is still rough

It is not perfect. I run into technical issues with it from time to time, so I will probably look at other options down the road. For now it works, and I would rather have a solution that is good enough today than keep the library stuck at home while I search for a perfect one.

You can read more about the rest of the setup on the home server page.
